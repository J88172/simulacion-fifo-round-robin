# simulacion-fifo-round-robin

Simulación de algoritmos de planificación FIFO y Round Robin en Java.

## Características

- Simulación de procesos
- Implementación de FIFO
- Implementación de Round Robin
- Cálculo de:
    - Tiempo de espera
    - Tiempo de retorno
    - Tiempo de finalización

## Tecnologías utilizadas

- Java
- Programación Orientada a Objetos (POO)
